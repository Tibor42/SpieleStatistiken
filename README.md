Spiele Statistik-App  

Eine Kotlin - Anwendung um Statistiken von Kartenspielen (oder anderen Gesellschaftsspielen) zu erfassen.
Es können Spieler, Spiele angelegt und dann Spiel-Endergebnisse eingetragen werden, so dass über einen längere Zeitraum
eine Statistik entsteht, in der man sehen kann, wie oft jemand gewonnen hat...

Motivation, Kotlin lernen und die Diskussion in unserer Familie wer wie oft beim Räuber-Romme (https://www.spielwiki.de/R%C3%A4uber-Romm%C3%A9) gewonnen hat :)
